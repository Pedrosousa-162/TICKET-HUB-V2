## 🎯 Fluxo Recomendado

Para configurar o projeto pela primeira vez:

1. 📖 Leia **START_HERE.md**
2. 📦 Siga **INSTALLATION.md**
3. 🗄️ Execute scripts SQL (veja **database/README.md**)
4. 💳 Configure **STRIPE_SETUP.md**
5. 📧 Configure **EMAIL_SETUP.md**
6. ✅ Teste com **PAYMENT_GUIDE.md**

Para usar o sistema:

1. 📖 Consulte **USAGE_GUIDE.md**
2. 🆘 Se tiver problemas, veja **TROUBLESHOOTING.md**
